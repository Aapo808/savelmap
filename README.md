Alkuperä:
Koko projekti sai ideansa kun devit halusi musiikkiharrastuksen yhdistää opintoihin.
Aiempi kitaratusta ja musiikin teorian osaaminen auttoi valtavasti projektin luonnissa. 

Perustieto:
Sovelluksen pääidea on auttaa käyttäjää visualisoimaan eri asteikoita ja samalla kuulemaan haluttu muutos.
Täydellinen esimerkki softan käytöstä on esim. jam trackien päälle improvisaatio sooloilu.

Manuaali:
ladattuasi repon tulee sinun kirjoittaa terminaaliin :
npm run dev
ja serverin luo:
npm run dev:server
